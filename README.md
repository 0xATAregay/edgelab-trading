# EdgeLab Trading

A standalone, local-first training dashboard for ES price-action study and funded evaluation readiness.

## Features
- Seven training milestones and 28 evidence-based checkpoints
- Daily study checklist
- Simulated trading journal with R-multiples and rule-adherence tracking
- Net expectancy and progress metrics
- JSON export/import backups
- Responsive dark-mode interface

## GitHub Pages
Set **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**.

Then visit https://0xataregay.github.io/edgelab-trading/

The website runs entirely from the root `index.html` with no build steps or dependencies. Data is stored only in the current browser's localStorage. Export a backup before clearing browser data or switching devices.

Educational simulation only. Completing milestones does not guarantee profitable trading or funded account eligibility.
